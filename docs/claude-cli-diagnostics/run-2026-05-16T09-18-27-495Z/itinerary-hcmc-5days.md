## 温馨提示

1. **签证**：提前办理电子签(e-Visa)，费用25美元
2. **货币**：1人民币 ≈ 3400越南盾，建议携带银联卡取现
3. **交通**：推荐使用Grab app打车，比出租车便宜方便
4. **防晒**：热带气候，注意防晒防蚊
5. **小费**：餐厅一般不需额外小费，服务费已含
6. **语言**：旅游景点英语基本通用，可下载翻译软件备用
